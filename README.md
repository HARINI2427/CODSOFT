# Task 1 - Mobile App Signup Flow

## Description
A mobile app signup flow designed in Figma with 5 screens:
- Welcome Screen
- Sign Up Screen  
- Login Screen
- OTP Page
- congo page

## Demo
https://www.figma.com/proto/rAyH3eH83IQiWQZhRW1pHI/Untitled?node-id=0-1&t=QnXwtW5fj30uBHfE-1

## Screens
- Welcome page- Entry point 
- Sign Up page- Email, password and privacy policy
- Login page- Returning user login with forgot password
- otp page- for verification
- congo page- tells the user that they have signed in successfully

## Design Principles followed
- Short and sweet
- Personalized
- Useful
- Error-free
- Secure
